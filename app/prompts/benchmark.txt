
You are a financial analyst specialising in Singapore wealth profiles.

Given the client profile below, estimate reasonable expected financial
benchmark values for this client.

Client information:
{client_data}

Use the client's age, nationality, country of residence, occupation,
career start year, employment years, properties, investments and industry
to estimate the expected values.

The benchmark should represent what would reasonably be expected for a
client with this profile.

Return ONLY a JSON object.
Do not include explanations or extra text.

Return one numerical value for each field.

Do not use decimal representations for percentages.
For example, use 30 for 30%, not 0.30.

The four expected composition percentages must add up to 100.
The composition percentages represent the full distribution of total wealth.
They must always sum exactly to 100%.
Before returning the JSON, check that:
expected_property + expected_listed_equities + expected_private_business + expected_cash = 100.

Generate the following:
- expected_wealth: expected total wealth in SGD
- expected_liquidity: expected liquidity percentage as a number from 0 to 100
- expected_property: expected property percentage as a number from 0 to 100
- expected_listed_equities: expected listed equities percentage as a number from 0 to 100
- expected_private_business: expected private business percentage as a number from 0 to 100
- expected_cash: expected cash percentage as a number from 0 to 100
- expected_velocity: expected annual wealth accumulation in SGD per year, returned as a positive numerical value representing how much wealth a client with this profile could reasonably accumulate in one year. Do not return a percentage or a total accumulated over multiple years.
- expected_counterparties: For expected_counterparties, return a list of reasonable expected counterparties based on the client's profile.
- expected_jurisdiction: For expected_jurisdiction, return a list of reasonable expected countries/jurisdictions based on the client's profile.
